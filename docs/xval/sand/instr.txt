아트온(초등 교실 그림 웹앱)에 새로 넣은 «샌드아트» 모드 코드 검수. 라이트박스 위 모래 그림: 모래 두께 격자(SandSim) + 화면(SandRender, 바뀐 사각형만 칠함) + 엔진(입력·되돌리기·기록·자동저장) + React 화면·무비.
성공조건(이것만 본다):
 (a) 결정성 — base(시작 판) + ops 를 차례로 apply 하면 지금 판과 같다. 무비 마지막 장면 = 지금 그림. 되돌리기 칸 1개 = ops 끝의 연산 1개(undo/redo/cancel/fold 어느 경로에서도 어긋나지 않음).
 (b) 입력 — 마우스·터치·펜에서 획이 끊기거나 브라우저에 가로채이지 않고, 두 번째 손가락·손바닥은 무시, pointercancel 이면 붓질 전 판으로 원복. 자동저장은 그린 것을 잃지 않는다(새로고침·탭 숨김·10초 연속 그리기).
 (c) 자원 — 웨일북(저사양 크롬북)에서 프레임마다 큰 할당·전체 판 재계산 없음, 메모리 상한(되돌리기 20칸·기록 2.4MB 접기)이 지켜진다. 잘못된 저장본(IndexedDB 손상·크기 불일치)이 와도 화면이 죽지 않는다.
